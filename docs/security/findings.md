## باقی‌مانده / نیاز به تصمیم یا امکانات بیرونی
- سرویس ایمیل (تأیید ایمیل، اطلاع تغییر رمز/قفل، ریست خودکار، ثبت‌نام بدون لو دادن ایمیل تکراری) — الان ریست با لینک یک‌بارمصرفِ ساخته‌شده توسط مالک است.

- فونت محلی (فایل woff2 لازم) و حذف `unsafe-inline` از style-src (بازنویسی استایل‌ها).
- استقرار: HTTPS، `COOKIE_SECURE`/`TRUST_PROXY`/`PUBLIC_URL`، BitLocker، کپی بیرونی بکاپ‌ها، رمزساز و 2FA حساب‌های هاست/گیت‌هاب/ایمیل (R1–R12).
- 2FA اختیاری برای مشتری: API آماده، رابط ندارد.
- gitleaks/semgrep/ZAP نصب نبودند؛ HIBP از سندباکس قابل تست نبود (fail-open).
